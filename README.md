# PixelAir Audio Bridge releases

Public **macOS downloads** for PixelAir Audio Bridge by Color+Light.

This repository does **not** contain application source. It exists so anyone can download a notarized build without access to the private codebase.

**Download site:** [audio.fluoraplant.com](https://audio.fluoraplant.com) (also [GitHub Pages](https://colorandlight.github.io/pixelair-macOS-audio-bridge-releases/))

## Install

1. Open the [download page](https://audio.fluoraplant.com) or the latest [Release](https://github.com/colorandlight/pixelair-macOS-audio-bridge-releases/releases).
2. Download `PixelAir-Audio-Bridge-x.y.z.dmg`.
3. Open the disk image and drag **PixelAir Audio Bridge** into Applications.

The app is Developer ID signed and notarized. It needs macOS 14 or later, plus a virtual audio device such as BlackHole or Loopback.

In the app: **PixelAir Audio Bridge → Check for Updates…**. Automatic checks run in the background but never install without confirmation.
